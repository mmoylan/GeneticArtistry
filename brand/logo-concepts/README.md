# Genetic Artistry: logo concepts

Not part of the website. These are logo explorations built from the site's minimal vector cannabis leaf
(seven palmate leaflets radiating from a hub, the same drawing as `src/components/LeafArt.astro`).
Every logo is generated by code, so colours, sizes and wording can be changed in one place and re-run.

```bash
node build.mjs              # the 8 first concepts   -> svg/01-… to svg/08-…
node build-vitruvian2.mjs   # the Vitruvian Leaf set -> svg/va-…, vb-…, vc-…  (current geometry)
```

Each concept is written twice: `-color.svg` (on white) and `-reverse.svg` (on dark green). Each SVG includes a
background rectangle; delete it for a transparent version. The scripts also write `sheet*.html` comparison pages
next to themselves (not committed).

## The leaf

```js
const LEAFLETS = [
  { len: 300, w: 44, rot: 0 },
  { len: 262, w: 40, rot: -28 }, { len: 262, w: 40, rot: 28 },
  { len: 210, w: 34, rot: -56 }, { len: 210, w: 34, rot: 56 },
  { len: 150, w: 28, rot: -82 }, { len: 150, w: 28, rot: 82 },
];
const petal = (len, w) => `M0 0C${-w} ${-len * 0.3} ${-w} ${-len * 0.7} 0 ${-len}C${w} ${-len * 0.7} ${w} ${-len * 0.3} 0 0Z`;
```

Hub at (0,0), leaflets point up (negative y), stem runs down. Solid versions separate overlapping leaflets with a
hairline "seam" stroke in the background colour.

## `build-leaf-a.mjs`: Leaf A (chosen, live on the website)

Concept 03 developed into a full set. Company title only ("GENETIC ARTISTRY"), no subtitle, transparent backgrounds.

```bash
node build-leaf-a.mjs          # svg/leaf-a-<layout>-<scheme>.svg and sheet-leaf-a.html
node build-leaf-a.mjs --site   # also writes ../../public/logo/* and ../../public/favicon.svg for the website
```

- **Layouts:** `mark`, `below` (title below), `above` (title above), `horizontal`, `icon` (rounded square for favicon and app icon).
- **Schemes:** `color`, `ivory` (for dark backgrounds), `mono-dark`, `mono-white` (single colour for print and embroidery). Icon: `color` (dark square) and `light`.
- The two leaflets are clipped to leave a 2-unit slit at the apex, so the A still reads in a single flat colour.
- The website's inline `Logo` component (`src/components/Logo.astro`) uses the same geometry and takes its colours from the site palette.
- The wordmark uses a fixed `textLength`, so spacing is identical whichever font loads.

## `build-vitruvian2.mjs`: Vitruvian Leaf (current)

The leaf as the figure in Da Vinci's proportion study. True proportions:

- Square side = the figure's height (here: leaf tip to stem foot).
- The circle is **larger** than the square and centred on the navel, about 0.6 of the height up. Its radius (about
  0.6 of the height) puts its bottom exactly on the square's bottom edge, so it rises above the head and pokes out
  past both sides.
- The circle centre (navel) sits above the square's centre. Both are marked with a dot.
- Ghost outlines show the second pose: side leaflets raised like arms, stem opened like legs.

| File | Concept |
| --- | --- |
| `va-true-proportions` | Natural leaf (stem 96, height 396). Circle R 238 centred 0.6 up. Recommended |
| `vb-long-stem` | The hub is the navel and circle centre, which needs a long stem (450). Tall and slender |
| `vc-plate-proportions` | Version A as an outline plate with degree ticks, for packaging and prints |

Geometry lives in the `GEO` table at the top of the file; stroke widths are given in px and divided by the group
scale so thin lines stay thin.

## `superseded/`

`build-vitruvian.mjs` and `svg/v1…v4` (Vitruvian Leaf, Plate, Seal, Lockup) used the wrong circle/square geometry
(circle hanging below the square). Kept only because the **Seal** (disc with cream leaf, for avatars) and the
**Lockup** (horizontal mark + wordmark) were not yet rebuilt on the true proportions. Rebuild those two from
`build-vitruvian2.mjs` if a Vitruvian direction is chosen.

## Notes

- Wordmarks are live text (Bitter and Montserrat, the site fonts) with Georgia/Arial fallbacks. Convert to outlines
  before sending anything to print.
- Colours: green `#1f4d33` / `#2f6b40`, tan `#c9b27a` (`#d6c28a` on dark), ink `#151c1a`, dark green `#12281c`.
- These are geometric drafts. A designer should refine whichever direction is chosen.
- `sheet.png` shows the first eight; `logo-sheet-vitruvian.png` shows the three Vitruvian versions.
